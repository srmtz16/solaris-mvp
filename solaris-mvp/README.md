# SOLARIS MVP

MVP visual de SOLARIS (Solar Intelligence & Monitoring), construido con Next.js App Router, TypeScript, Tailwind CSS, componentes estilo shadcn/ui, Recharts y Lucide Icons.

La aplicación usa datos simulados y no incluye autenticación, backend, base de datos, APIs ni conexión con inversores reales.

## Ejecutar

```bash
npm install
npm run dev
```

## Compilar

```bash
npm run build
```

## Desplegar en Vercel

Conecta este repositorio en Vercel, selecciona la carpeta `solaris-mvp` como root directory y usa la configuración automática de Next.js.
